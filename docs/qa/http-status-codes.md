# HTTP status codes

What each status from DATEV means and whether it is retried.

36 questions. Generated by `npx tsx scripts/build-qa.ts`. Do not edit by hand.

### What does HTTP 200 from DATEV mean?

Success. Typed tools still check the shape before showing it.

### Does the server retry HTTP 200?

No. The answer is returned as it is.

### What does HTTP 201 from DATEV mean?

Created. A write succeeded.

### Does the server retry HTTP 201?

No. The answer is returned as it is.

### What does HTTP 202 from DATEV mean?

Accepted. DATEV will process it as a job, for example an EXTF import.

### Does the server retry HTTP 202?

No. The answer is returned as it is.

### What does HTTP 204 from DATEV mean?

Success without a body.

### Does the server retry HTTP 204?

No. The answer is returned as it is.

### What does HTTP 400 from DATEV mean?

DATEV rejected the request. The sweep recorded only the status, not DATEV's reason, so the cause is not known. Call it again and read the answer body.

### Does the server retry HTTP 400?

No. The answer is returned as it is.

### What does HTTP 401 from DATEV mean?

The app is not subscribed to the product or the scope was not granted.

### Does the server retry HTTP 401?

No. The answer is returned as it is.

### What does HTTP 403 from DATEV mean?

### Does the server retry HTTP 403?

No. The answer is returned as it is.

No. The answer is returned as it is.

### What does HTTP 422 from DATEV mean?

### Does the server retry HTTP 422?

No. The answer is returned as it is.

### What does HTTP 429 from DATEV mean?

DATEV's rate limit. Reads retry with Retry-After, writes are retried only for this status.

### Does the server retry HTTP 429?

Yes, for reads and writes, as long as the wait fits the call budget.

### What does HTTP 500 from DATEV mean?

DATEV answered with a server error. The sweep recorded only the status, so read the answer body for DATEV's reason.

### Does the server retry HTTP 500?

No. The answer is returned as it is.

### What does HTTP 502 from DATEV mean?

Gateway error. Reads retry it.

### Does the server retry HTTP 502?

Yes, for reads only, up to three attempts within the call budget.

### What does HTTP 503 from DATEV mean?

Service unavailable. Reads retry it.

### Does the server retry HTTP 503?

Yes, for reads only, up to three attempts within the call budget.

### What does HTTP 504 from DATEV mean?

Gateway timeout. Reads retry it.

### Does the server retry HTTP 504?

Yes, for reads only, up to three attempts within the call budget.
