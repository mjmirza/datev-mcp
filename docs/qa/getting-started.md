# Getting started

What datev-mcp is, who it is for, and the first hour with it.

20 questions. Generated by `npx tsx scripts/build-qa.ts`. Do not edit by hand.

### What is datev-mcp in one sentence?

A Model Context Protocol server that lets an AI assistant read from and, after your explicit confirmation, write to the official DATEV APIs.

### Who is it built for?

Tax advisors, bookkeepers and the developers who build tools for them. It assumes someone with a DATEV developer account sets it up once.

### Which AI assistants can use it?

Any client that speaks MCP over standard input and output, for example Claude Code, Claude Desktop, Cursor and VS Code with Copilot agent mode.

### Do I need to know the DATEV API to use it?

No. You ask in plain words. The assistant picks the tool, and for unusual tasks it searches the operations with `datev_search_operations` (203 of the 209, health checks left out).

### How long does the first setup take?

About 15 to 20 minutes, most of it in the DATEV developer portal registering an app and subscribing products.

### What do I need before I start?

Node.js 22 or newer, a DATEV developer account, an app registered for the sandbox, and its client id and client secret.

### How do I install it?

Clone the repository, run `npm install`, `npm run specs` and `npm run build`. The README walks through it with screenshots.

### Why is there a separate `npm run specs` step?

DATEV's terms do not allow passing their API documentation on, so the specs are not in the repository. The command downloads DATEV's public specs to your machine and builds the operation index from them.

### Where do my DATEV credentials go?

Into `.env/.env.local` (git ignores it) or, better, into a password manager that injects `DATEV_CLIENT_ID` and `DATEV_CLIENT_SECRET` when the server starts.

### How do I sign in to DATEV?

Run `node --env-file=.env/.env.local dist/index.js login`. A browser opens at DATEV, you sign in and grant the permissions, and the session is saved on your machine.

### How do I know the setup works?

Run `node --env-file=.env/.env.local dist/index.js doctor`. Six lines marked OK mean credentials, index, session, token and two live DATEV calls all work.

### How do I connect it to Claude Code?

Run `claude mcp add datev -- node --env-file=/absolute/path/.env/.env.local /absolute/path/dist/index.js` once.

### What is a good first question to ask?

"Which clients can I reach in DATEV?" It calls `datev_list_clients` and shows your clients with their active data services, up to 5,000.

### Is there a hosted version?

No. It runs on your own machine, which keeps the DATEV session and any downloaded files local.

### Does it cost anything?

The software is source-available and free for an individual's personal evaluation. Business use needs a license from the author. DATEV charges separately for production access.

### Which language does it speak?

The tools work with any language your assistant speaks. EXTF checks can report findings in German or English with `lang`.

### Can I try it without real client data?

Yes, that is the default. It talks to the DATEV sandbox, which holds test clients such as 455148-1.

### What does the sandbox test data look like?

Four test clients with made-up names, a fiscal year 2023, a chart of accounts with 2,061 accounts and 11,562 postings for client 455148-1. The README shows real answers.

### Where are the screenshots of the results?

In the README section "What the answers look like" and in `docs/images/`.
