# Questions people ask about the DATEV API

Real questions from DATEV's community, Reddit, YouTube walkthroughs and integration forums, researched with /last30days on 2026-11-07, answered for this server.

18 questions. Generated by `npx tsx scripts/build-qa.ts`. Do not edit by hand.

### DATEV's service names and API product names differ. How do I keep them apart?

DATEV switches on data services per client, for example Buchungsdatenservice or Rechnungsdatenservice. Your app subscribes to API products such as accounting-extf-files. `datev_list_clients` shows each client's services, and `datev_search_operations` finds the matching operations.

### Do I need the right scopes for every call?

For most. 72 of the 209 operations declare no scope and depend on the product subscription or an API key header instead, and several products share scopes. The server requests every known scope by default, and `openid` always.

### Is a DATEV service activated per app or per client?

Both matter. Your app must be subscribed to the API product, and the client must have the data service switched on. `datev_list_clients` shows the client side.

### Why does a call answer 401 while another product works?

The app is subscribed to one product but not the other, or the scope for it was not requested. Subscribe in the portal and log in again.

### Is the DATEV API plug and play?

No. Apps start in the sandbox, each product is a separate subscription, and production needs DATEV's approval. This server handles the protocol part.

### How do I create booking proposals from invoices?

That is the Rechnungsdatenservice side of DATEV (the accounting-dxso-jobs product). Its job operations can be found with `datev_search_operations` and called with `datev_call`, which previews every write. Attach the invoice file with `datev_upload_file` on `accounting-dxso-jobs.post_clients_client_id_dxso_jobs_job_id_files`, which also previews before sending.

### Can I export bookings from my ERP to DATEV automatically?

Yes. Build an EXTF batch with `datev_write_extf_batch`, check it, and import it with `datev_upload_extf` after you confirm the preview.

### How do I send receipts to my tax advisor's DATEV?

Upload them with `datev_upload_document` for the client, if the client has the document service switched on.

### Why does my EXTF import fail on account numbers?

The account length in the header must match the client's setting. Mixed 4 and 6 digit accounts are a frequent cause in DATEV's community.

### Can I use DATEV with n8n or other automation tools?

Yes, through any MCP-capable agent. Writes through `datev_call`, `datev_upload_extf` and `datev_upload_document` need a preview and a confirmation code. Writing an EXTF file locally and the read-only postings export job need no code.

### Is DATEVconnect the same as the DATEV online APIs?

No. DATEVconnect talks to DATEV software installed in an office. This server uses the DATEV online APIs in the DATEV data center.

### Where do I get sample data for practice?

The DATEV sandbox includes test clients, for example 455148-1 with a full fiscal year 2023.

### Can I build accounting software on top of this?

Yes, within the license. DATEV's own rules still apply, including production approval.

### Does an AI assistant make DATEV bookings safer or riskier?

It can be either. This server keeps a person in charge of every write with a preview and a code tied to that exact request.

### What other DATEV MCP servers exist?

There are other projects, for example a DATEV connector in HelpCode-ai/anythingmcp. Compare coverage, write safety and tests before choosing.

### How do I learn the DATEV API quickly?

Ask the assistant to search operations by plain words and describe one. It reads the operation index that `npm run specs` built on your machine.

### Can I get cost centres (KOST1, KOST2) into DATEV?

Yes. `datev_write_extf_batch` takes optional `kost1` and `kost2` per row, each up to 36 letters, digits, spaces or underscores. Values DATEV would flag, such as `A-1`, are refused before the file is written.

### How do I avoid duplicate imports?

Each confirmation code is accepted once, so one approval cannot be sent twice. If the send fails after the code was accepted, request a new preview. Writes are never retried.
