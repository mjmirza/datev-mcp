# The twelve tools

What each tool does and how to call it.

30 questions. Generated by `npx tsx scripts/build-qa.ts`. Do not edit by hand.

### Which tools are there?

`datev_list_clients`, `datev_list_fiscal_years`, `datev_sums_and_balances`, `datev_account_postings`, `datev_find_accounts`, `datev_validate_extf`, `datev_write_extf_batch`, `datev_upload_extf`, `datev_upload_document`, `datev_search_operations`, `datev_describe_operation` and `datev_call`.

### When should I use a typed tool instead of `datev_call`?

Whenever one exists. Typed tools page through lists and shape DATEV's answers. They are not a guarantee against bad data: `datev_find_accounts` skips malformed account rows, and `datev_list_clients` stops at 50 pages of 100 (5,000 clients) and then reports `complete: false`.

### What does `datev_list_clients` return?

The clients your login can reach, with client id, name, number and the data services DATEV has switched on. It pages through DATEV's 100-per-request limit, stops after 50 pages (5,000 clients), and says `complete: false` if there were more.

### What is a client id?

DATEV's id for a client, made of consultant number and client number, for example `455148-1`. Most other tools need it.

### What does `datev_list_fiscal_years` need?

A `client_id`. It returns fiscal year ids such as `20230101`, which you pass to the accounting tools.

### What is a fiscal year id?

An eight digit date `YYYYMMDD`, the first day of the fiscal year, for example `20230101`.

### What does `datev_sums_and_balances` return?

Per account the opening balance, yearly debit and credit, the balance with its S or H side, and monthly values.

### How do I keep the sums and balances answer small?

Pass `account_prefix`, for example `12` for bank accounts, and `limit` up to 500.

### What does `datev_account_postings` return?

Posted bookings for a fiscal year, with date, account, contra account, amounts, text and more, read from every page DATEV reports.

### Why does `datev_account_postings` sometimes return `ready: false`?

DATEV prepares postings as a background job. Call again with the returned `job_id`. No second job is started.

### How do I continue a partial postings read?

Call again with `job_id` and `from_page`. The answer tells you where it stopped.

### How do I get postings for one account only?

Pass `account` with the account number prefix.

### What does `max_wait_seconds` do?

How long the postings tool waits for DATEV's job, between 5 and 50 seconds. Most MCP clients cancel a call after about 60 seconds.

### What does `datev_find_accounts` do?

Searches the client's real chart of accounts by number prefix or words, for example `1200` or `Bank`. It works with SKR03, SKR04 and custom charts.

### Is the chart of accounts cached?

For 10 minutes in memory, keyed to your login, so repeated searches are fast and never cross logins.

### What does `datev_validate_extf` do?

Checks an EXTF booking file locally and lists errors and warnings, without sending anything to DATEV.

### What does `datev_write_extf_batch` do?

Builds a valid EXTF Buchungsstapel file from rows you describe and checks it. It only writes a local file.

### What does `datev_upload_extf` do?

Imports an EXTF file into a client. The first call is a preview with a confirmation code, the second call with that code sends it.

### What does `datev_upload_document` do?

Uploads a receipt or invoice for a client, after the same preview and confirmation step.

### What does `datev_search_operations` do?

Finds DATEV operations by keywords, optionally limited to one product or to writes only. Health check operations are left out, so 203 of the 209 operations are searchable.

### What does `datev_describe_operation` do?

Shows the parameters, request body schema, scopes and servers of one operation, from the operation index that `npm run specs` built on your machine.

### What does `datev_call` do?

Calls a DATEV operation by id. Reads run directly, writes return a preview first and need `confirm: true` with the matching `confirm_token`. It sends JSON or text bodies, never a file. 18 operations take a file: 12 require one and cannot be used through it, 6 can be called without a file. `datev_upload_extf` and `datev_upload_document` send files for two of them.

### How do I pass path values to `datev_call`?

As `path_params`, for example `{"client-id": "455148-1"}`. Each value is checked against DATEV's schema.

### How do I save a PDF from `datev_call`?

Pass `save_to` with an absolute path. The bytes are saved exactly, with their SHA-256 in the answer.

### What if I do not pass `save_to` for a PDF?

Small binaries come back as base64 with their SHA-256. Large ones are refused with a hint to use `save_to`.

### Can `datev_call` send custom headers?

Yes. Any header except the reserved ones (Authorization, the DATEV client id and secret, Host, Cookie, and the body headers Content-Type, Content-Length, Content-Encoding and Transfer-Encoding; set the body type with `content_type` instead) can be sent, as long as it has no line break. Required header parameters, for example `X-API-Key`, are checked before anything is sent.

### Can I send a text body with `datev_call`?

Yes. Pass `body` as a string and set `content_type` for text content types.

### Which tools change data?

`datev_upload_extf`, `datev_upload_document`, and `datev_call` on write operations, as long as no file is needed (it never sends files). These need a preview first. `datev_account_postings` also starts DATEV's postings export job, without a preview, because it changes no bookings.

### Which tools only work locally?

`datev_validate_extf`, `datev_write_extf_batch`, `datev_search_operations` and `datev_describe_operation` never call DATEV.

### How does the assistant know which tool to use?

Each tool carries a title and description. Most clients pick the right one from your question.
