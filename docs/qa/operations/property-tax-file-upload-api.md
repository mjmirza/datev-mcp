### How do I call `property-tax-file-upload-api.uploadfile`?

Use `datev_upload_file` with `operation_id: "property-tax-file-upload-api.uploadfile"` and `files` mapping the part `file` to local file paths, plus `fields` for `metadata` where needed. The first call returns a preview and a confirmation code. Nothing is sent until the assistant calls again with `confirm: true` and that code.

### Does `property-tax-file-upload-api.uploadfile` change data in DATEV?

Yes. `datev_upload_file` sends it only after the preview and confirmation code, and it is never retried.

### What should I check if `property-tax-file-upload-api.uploadfile` fails?

Read the HTTP status in the answer. 401 or 403 means a missing subscription or scope, 404 an unknown id, 429 the rate limit, and a refused confirmation code means it was missing, expired, already used, or the request changed after the preview. The troubleshooting page explains each one.
