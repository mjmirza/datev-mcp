# MCP clients

Running the server in different assistants.

10 questions. Generated by `npx tsx scripts/build-qa.ts`. Do not edit by hand.

### Which transport does it use?

MCP over standard input and output.

### How do I add it to Claude Desktop?

Add an entry to the MCP servers config with `command: node` and args `--env-file=/absolute/.env/.env.local` and `/absolute/dist/index.js`.

### How do I add it to Cursor?

Add it as a stdio MCP server with the same command and arguments.

### How do I add it to VS Code?

Add a stdio server in the MCP settings with the same command and arguments.

### Can I use a password manager launcher?

Yes. Point the client at the launcher instead of node. The launcher reads the credentials and starts the server.

### Does it work with several clients at once?

Yes. Each client starts its own process and they share the session safely.

### Can the client cancel a long call?

Yes. Cancellation aborts the DATEV request in flight.

### Why do some clients cut calls at 60 seconds?

That is the client's own limit. The server's 55 second budget covers each DATEV call, including getting a token.

### Should my client ask before tool calls?

For writes, yes. Require approval for any call with `confirm: true`.

### Can I limit which tools the assistant sees?

Most clients let you disable tools. Disable the write tools if you only want reading.
