# Sandbox, production and compliance

Moving from test data to real clients.

15 questions. Generated by `npx tsx scripts/build-qa.ts`. Do not edit by hand.

### Can I use it with real client data today?

Only after DATEV has approved your app for production and you have a data processing agreement with your AI provider. Until then use the sandbox.

### What is DATEV's production approval?

A review by DATEV (Technische Prüfung) before an app may call the production APIs. It is paid and done per app.

### What is the difference between sandbox and production hosts?

The sandbox uses DATEV's sandbox servers and test data. The server picks the right host from DATEV's specs based on `DATEV_ENV`.

### Do sandbox results predict production results?

For request format, yes. For data and permissions, no. The sandbox only has test clients and some products answer differently there.

### Why do some products return 500 with "Sandboxing policy error"?

DATEV's sandbox gateway refuses that resource for your app. The request itself was fine. Ask DATEV to enable the product for the sandbox.

### Does it comply with GDPR?

The server stores no client data apart from the in-memory chart cache and files you save on purpose. GDPR obligations come from how you use it, especially which AI provider sees the answers. COMPLIANCE.md lists the steps.

### Is this an official DATEV product?

No. It is independent and not affiliated with, endorsed by, or sponsored by DATEV eG.

### Can I use the DATEV logo?

No logo or artwork is in the repository, and the screenshots blur it. DATEV is a registered trademark of DATEV eG.

### Are DATEV's API docs redistributed?

No. The specs and the operation index built from them stay out of git. Each developer downloads their own copy.

### What does the license allow?

Personal, non-commercial evaluation by an individual with the credit kept. Business use and derivative works need written consent.

### Can my company use it?

With a commercial license. Reach out through next8n.com.

### Does it handle the EU AI Act?

The server is a tool, not an AI system. If you build an assistant on it for others, tell people they are talking to an AI and keep a person in the loop for writes.

### Who is responsible for a wrong booking?

The person who confirmed it. The preview exists so a human checks every write before it runs.

### Should I let the assistant confirm writes on its own?

No. Configure your MCP client to ask you before calling a write with `confirm: true`.

In `docs/COMPLIANCE.md`.
