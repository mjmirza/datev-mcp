# EXTF booking files

Building, checking and importing DATEV Buchungsstapel files.

25 questions. Generated by `npx tsx scripts/build-qa.ts`. Do not edit by hand.

### What is an EXTF file?

DATEV's text format for importing data such as booking batches (Buchungsstapel). The file name starts with `EXTF_` and the first line is a header.

### Which EXTF categories does the server write?

`datev_write_extf_batch` writes booking batches, category 21, format version 13.

### Which encoding is used?

Windows-1252, as DATEV expects.

### What goes into one booking row?

Amount in cents, side `S` or `H`, account, contra account, day, month, optionally BU key, document field (Belegfeld 1) and text.

### Why is the amount in cents?

Integer cents avoid rounding errors. 11900 means 119,00 EUR.

### What do S and H mean?

Soll (debit) and Haben (credit).

### What is the Sachkontenlänge?

The number of digits of G/L accounts for that client, usually 4 or 8. Pass it as `account_length`.

### What happens if the account length is wrong?

DATEV rejects or misreads the import. Mixed lengths are a common cause of failed batches reported in DATEV's community. Use the length set for the client.

### How do I find a client's account length?

Look at the account numbers `datev_find_accounts` returns. The sandbox client 455148-1 uses 8 digits.

### What is `wj_start`?

The first day of the client's fiscal year, `YYYYMMDD`, for example `20230101`.

### What are `from` and `to`?

The period the batch covers, both `YYYYMMDD`, inside one fiscal year.

### What is the batch label?

The Bezeichnung shown in DATEV, at most 30 characters.

### What are Berater and Mandant?

Consultant number and client number. Together they form the client id, for example 455148 and 1 for `455148-1`.

### Can I choose the chart of accounts?

Pass `skr` as `03` or `04`, or leave it empty.

### What is a BU key?

A booking key (BU-Schlüssel) that controls tax handling. Leave it empty for automatic accounts.

### How many rows can one batch hold?

Up to 99,999 rows per file.

### Does writing a file send anything to DATEV?

No. It only writes a local file and checks it.

### Can I check a file someone else made?

Yes, with `datev_validate_extf` by `file_path` or by passing the content.

### What does an import return?

On success DATEV answers 202 with a job location. The sandbox accepted a real import from this server on 2026-11-07.

### Is the import immediate?

DATEV processes it as a job. The answer contains the job location to check later.

### Can I import into a closed (festgeschriebene) period?

DATEV decides that, not the server. Corrections to fixed periods are restricted in DATEV.

### Which DATEV data service do imports need?

The client needs the booking data service switched on. `datev_list_clients` shows each client's active services.

### Which EXTF library is used?

An MIT licensed EXTF library, listed with its source in `docs/CREDITS.md`.

### Is the EXTF API deprecated?

DATEV's portal has marked an older version as deprecated. The server uses the current accounting-extf-files API definition 3.0.1, which DATEV lists as online.

### Does the check catch every DATEV import error?

It catches format and structure errors. Account-specific rules, such as a closed period, are only known to DATEV.
