# Documents and receipts

Uploading receipts and invoices.

13 questions. Generated by `npx tsx scripts/build-qa.ts`. Do not edit by hand.

### Which file types can I upload?

PDF, JPG, PNG, TIFF, GIF, BMP, XML, TXT and CSV.

### Why was my ZIP refused?

DATEV does not accept ZIP files for documents. Upload the files one by one.

### What is a document type?

DATEV's category for the receipt, for example Rechnungseingang or Rechnungsausgang, at most 30 characters.

### Can I add a note?

Yes, up to 255 characters with `note`.

### What does the preview show?

File name, size and type, the target client and environment, plus the confirmation code. The code also binds the file's SHA-256 and the metadata.

### Which DATEV service receives the documents?

The Belegbilderservice, through the accounting-documents API product.

### Is the file read twice?

The file is checked and hashed for the preview, and the upload must match that hash or it is refused.

### Can I upload from a hidden folder?

No. Hidden folders and key-like names are always refused.

### How large can a document be?

`datev_upload_document` refuses files over 20 MiB. DATEV may set a lower limit per product.

### Can I download a document from DATEV?

Yes, with `datev_call` on the matching read operation and `save_to`.

### Which client service do uploads need?

The client's document service must be switched on. Check it in `datev_list_clients`.

### Why did the sandbox answer 400 for accounting-documents?

### Can I upload many receipts at once?

Ask the assistant to upload them one by one. Each upload gets its own preview.
